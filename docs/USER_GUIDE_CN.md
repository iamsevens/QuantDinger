## 1. AI 助手（AI 智能分析）

**路由**：`/ai-asset-analysis` | **页面标题**：「AI 智能分析」

### 1.1 页面结构

当前版本以 **AI 副驾驶（Copilot）工作台** 为核心布局，三栏结构：

- **左侧**：聊天记录面板（历史会话列表 + 新建对话按钮）
- **中间**：Copilot 对话区（输入框 + 消息流 + 分析报告卡片）
- **右侧**：观察名单 + AI 定时分析任务面板

顶部可能有 **AI 交易机会雷达条**（默认关闭，配置项 `showOpportunityRadar` 控制），每小时扫描超买/超卖机会。

> 旧版界面有「即时分析」/「资产池与定时任务」双 Tab、快捷分析条、独立统计区、组合体检按钮，但**当前组件代码中零引用这些旧版 key**，实际界面以 Copilot 工作台为主。

### 1.2 即时分析

**选择标的**（三种路径）：

1. **Copilot 右栏观察名单**：点击标的名 → 自动锁定到输入框上下文；点击消息图标(💬)自动填入诊断 prompt；点击时钟图标(🕐)创建定时任务
2. **Copilot 输入框符号选择器**：点击输入框上方的符号下拉 → 选择或搜索标的 → 锁定上下文
3. **机会雷达卡片**：点击雷达条中的机会卡片 → 自动触发 AI 分析

**一键分析**：
- 手动输入自然语言 prompt（如「诊断 BTC/USDT 1 小时趋势」），Enter 发送
- 或点击快捷任务（见 1.4）
- 分析中显示「分析正在进行中……」，polling 间隔 2.5 秒，最长 3 分钟
- 完成后在消息流中嵌入 `FastAnalysisReport` 报告卡片，失败则显示错误

**批量定时任务**（弹窗「批量定时任务」）：
- 标题：「批量定时任务」
- 描述：「将为选中的 {count} 个标的创建定时 AI 分析任务，系统将按设定周期自动分析并推送报告。」
- 分析周期下拉：1h / 4h / 12h / 1d
- 通知渠道多选：Email、Telegram、Webhook
- 确认后批量创建，完成提示：「批量定时任务已创建」

### 1.3 资产池与定时任务

**添加自选股（观察名单）**：
1. Copilot 右栏「观察名单」面板 → 点击「添加」按钮
2. 弹出「添加到关注列表」弹窗
3. 顶部市场 Tab 切换：加密货币 / 美股 / A股 / H股 / 外汇 / 期货
4. 搜索输入（placeholder：「搜索或输入符号」），回车搜索
5. 选中标的 → 点击确定 → 提示「已添加到关注列表」/「添加失败」

**创建虚拟持仓**：
1. Copilot 右栏观察名单 → 标的名右侧菜单 → 「创建持仓（虚拟仓）」
2. 填写：方向（做多/做空）、数量、买入单价
3. 保存后可在资产池中查看

**创建 AI 定时任务（单条）**：
1. 观察名单中 → 标的名下方时钟图标 → 「创建定时分析」弹窗
2. 标的（已锁定不可编辑）
3. 分析周期下拉：1h / 4h / 12h / 1d
4. 通知渠道多选：站内通知 / 邮件 / 电报 / Webhook
5. 提示：「AI 将按周期重新检查此标的并保留记录。」
6. 保存后提示「已创建定时分析」

**定时任务管理**：
- 点击「任务管理」按钮 → 右侧滑出抽屉（420px 宽）
- 每个任务显示：名称（默认 `AI-{symbol}-{interval}m`）、状态标签（运行中/已暂停）、执行间隔 + 下次执行时间
- 操作：启停按钮（提示「已暂停任务」/「已启用任务」）、编辑（提示「定时分析已更新」）、删除（确认「确定要删除此定时任务？删除后不可恢复。」→「任务已删除」）

Copilot 右栏「AI 定时分析任务」面板实时展示所有任务，支持暂停/恢复/删除。

### 1.4 AI 副驾驶（Copilot）

**输入框**（底部固定区域）：
- placeholder：「例如：诊断 BTC/USDT 1 小时趋势，或者上传图表截图并询问入场风险是否可以接受……」
- 发送：Enter；换行：Ctrl+Enter / Shift+Enter
- 符号上下文栏：默认「未固定，AI 将从您的消息中推断。」→ 选中后显示「这个符号 + 具体代码」
- **上传图片**：点击上传按钮或粘贴截图 → AI 可分析图表

**快捷提示**（欢迎界面 + 快速工具弹窗，8 个卡片）：

| 快捷任务 | 提示词模板 |
|----------|-----------|
| 诊断符号 | 「诊断 {symbol}：趋势、动量、支撑/阻力、流动性和风险。」 |
| 图表截图分析 | 「粘贴或上传图表图片，判断该设置是否可交易，并设置止损、止盈和失效点。」 |
| 图表指标研究 | 「请为 {target} 创建一个展示趋势和可能转折的图表指标……」 |
| 策略研究 | 「请为 {target} 创建一个可执行交易策略，包含入场、出场、风控和仓位规则……」 |
| 交易计划 | 「请为 {symbol} 制定一份可执行的交易计划：方向判断、关键价位、入场触发、止损、止盈、仓位控制……」 |
| 新闻与事件 | 「搜索与 {symbol} 相关的近期新闻和事件；区分事实、解释和不确定性。」 |
| 宏观数据 | 「审查 CPI、FOMC、利率、GDP 和 PCE 等宏观数据，并解释其对市场的影响。」 |
| 机会雷达 | 「扫描 {symbol}，查找未来 24 小时内可能出现的机会，并设置触发条件和失效条件。」 |

**可生成的草稿类型**：

| 类型 | 触发方式 | 后续跳转 |
|------|----------|----------|
| 图表指标 | 快捷任务「图表指标研究」或 prompt 含指标意图 | 「打开指标编辑器」→ `/indicator-ide` |
| 交易脚本 | 快捷任务「策略研究」或 prompt 含策略意图 | 「打开目标页面」→ `/strategy-ide` |
| 策略模板参数 | 快捷工具「策略研究」或 robotTemplate skill | `/strategy-center` |

生成后可直接点击「回测」→ `/backtest-center`，或「导出 PDF」。

**Composer 策略草稿引导**：
- 图表指标模式：「你想在图表上看见什么？」→ 建议点选「趋势方向」「买卖提示」「支撑阻力」
- 交易脚本模式：「你希望策略怎么交易？」→ 建议点选「入场规则」「止损止盈」「仓位管理」

**会话管理**：
- 左栏「聊天记录」面板 → 会话列表（最多 30 条）→ 点击加载历史
- 「新对话」按钮创建新会话
- 悬停会话卡片 → 删除图标 → 确认「删除此对话？」→ 「对话已删除」

### 1.5 AI 交易机会雷达

（默认关闭，配置启用后显示）

- 标题：「AI 交易机会雷达」，副标题：「每小时更新」
- 轮播卡片：标的代码 + 市场标签（🇨🇳 A股 / 🪙 加密 / 💱 外汇 / 🇭🇰 H股 / 📈 美股）、当前价格、涨跌幅、信号类型（超买/超卖）、信号原因
- Crypto 标的额外显示「立即交易」按钮
- 点击卡片 → 自动开始 AI 分析
- 空态：「暂无交易机会」

### 1.6 分析报告卡片（FastAnalysisReport）

AI 分析完成后，消息流中嵌入报告卡片，包含：

- **决策徽章**：最终决策（BUY / SELL / HOLD）+ 置信度圆环
- **价格信息**：当前价格 / 建议入场 / 止损价 / 止盈目标
- **四维评分**：技术面 / 基本面 / 情绪面 / 综合评分（进度条 + 分数）
- **关键理由与风险**：核心理由列表 + 风险提示列表
- **技术指标**（PRO 标签）：RSI(14)、MACD(12,26,9)、均线趋势、ATR(14)、布林带宽、20日位置%、量比、支撑/阻力、波动性
- **反馈区**：「这次分析对您有帮助吗？」→ 「有帮助」/「需改进」
- **分析耗时**：「分析耗时: {ms}ms」

> 若后端返回 `performanceStats` 数据，报告卡片内还展示：历史分析次数、准确率、平均置信、平均收益。

### 1.7 分析报告加载步骤

分析中显示 4 步进度：
1. 获取实时数据
2. 计算技术指标
3. AI 深度分析
4. 生成报告

## 2. 市场（社区商城）

**路由**：`/indicator-community` | **页面标题**：「市场」

> 这不是自选股页。自选列表在「标的池」页（`/universe-manager`）的第三 Tab「自选列表」。「市场」是一个**指标/策略的商城**，搜索框搜索的是指标名称或描述，不是股票代码。

### 2.1 页面结构

**根 Tab**（三栏）：

| Tab | 文案 | 说明 |
|-----|------|------|
| 市场 | `community.title` = 「市场」 | 浏览商城 |
| 我的发布 | `community.authorTab` = 「我的发布」 | 作者后台 |
| 审核管理 | `community.admin.reviewTab` = 「审核管理」 | 仅管理员可见 |

**资产类型二级导航**（在「市场」Tab 内，单选按钮组）：

| 类型 | 文案 | 说明 |
|------|------|------|
| 指标 | `community.tabIndicators` = 「指标」 | 图表/技术指标类 |
| 策略 | `community.tabScriptTemplates` = 「策略」 | Strategy API V2 / 脚本策略 |

> 字典中存在 `community.tabBotPresets` = 「策略模板」键，但**当前编译产物中未挂载到市场页面**。策略模板入口在「实盘」页。

### 2.2 浏览、搜索与排序

**顶部右侧筛选区**（从左到右）：

1. **搜索框**：placeholder = 「搜索指标名称或描述...」
2. **价格类型过滤**（单选）：全部 / 免费 / 付费 / VIP免费
3. **代码可见性**（下拉）：全部 / 源码可见 / 源码隐藏
4. **价格区间**（两个数字输入框，配「-」分隔 + 「搜索」按钮）
5. **重置按钮**：「重置」
6. **排序下拉**：
   - 指标模式默认：「最热门」
   - 策略模式默认：「综合评分」
   - 其它：「最新发布」「评分最高」「价格从低到高」「价格从高到低」
7. **「我的购买」** 链接按钮

**底部**：分页（「共 N 个」）、风险提示条、空状态（「暂无指标」/「暂无已发布的脚本」）

### 2.3 指标卡展示的信息

**封面区**：
- 预览图（若有）或渐变色封面 + 双字母缩写 + 指标名
- 徽章：类型标签（「图表指标」/「策略」）、VIP免费标签、价格标签（「免费」/「{price} 积分」）、「我的指标」/「已购买」标签
- 策略资产：综合评分色标（0-100，>=80 金色、>=60 绿色、>=40 黄色、<40 红色）

**内容区**：
- 标题 + 描述（无描述：「暂无描述」）
- 策略资产 KPI 网格：总收益率、年化收益率、夏普、最大回撤
- 图表指标「视觉能力」区块：代码可见性、参数数、图表标记、图层叠加
- **过拟合风险仪表盘**（见 2.8）
- 适用标签（最多 2 个标的 + 2 个周期，超出 "+N"）
- 作者头像 + 昵称
- 统计：获取数、评分、浏览数

### 2.4 免费获取 / 积分购买

**进入**：点击指标卡 → 弹出 `IndicatorDetail` 模态框。

| 场景 | 按钮文案 | 动作 |
|------|----------|------|
| 免费资产 | 「免费获取」 | POST `/api/community/indicators/{id}/purchase` |
| 付费资产 | 「{price} 积分」+ 「立即购买」 | 同上 |
| 已购买 | 「同步代码」/「恢复副本」+ 「立即使用」 | 同步/恢复本地副本 |
| 自己的资产 | 「我的指标」 | 按钮禁用 |

**成功提示**：
- 指标资产：「购买成功！指标已添加到您的指标列表」
- 策略资产：「已添加到Strategy API V2 策略，可在Strategy API V2 策略页编辑与回测」

**积分不足**（后端返回 `insufficient_credits`）：
- 「积分不足：购买需要 {required} 积分，当前只有 {current}，还差 {shortage}。」

### 2.5 评分与评论

在 `IndicatorDetail` 模态框「用户评价」区块：

1. 点击星标评分（1-5 星），未评星时提交会提示「请先选择评分」
2. 输入评论文本（placeholder：「分享您的使用体验...」），最大 500 字
3. 点击「提交评论」
4. 已评论后显示「您已评论此指标」+ 「修改评论」按钮
5. 编辑时按钮变为「更新评论」
6. 时间格式：刚刚 / N分钟前 / N小时前 / N天前
7. 「加载更多」按钮加载更多评论
8. 空态：「暂无评论」

### 2.6 复制源码 / 同步最新代码 / 恢复本地副本

购买后在指标卡和「我的购买」列表中出现：

**恢复本地副本**（本地副本缺失时）：
- 按钮：「恢复副本」（图标 cloud-download）
- 悬停提示：「你的本地副本已删除，可从已购买内容重新生成」
- 确认弹窗：「恢复本地副本？」+ 「将根据市场中当前可用版本重新生成一份本地副本，你无需重新购买。」
- 成功：「本地副本已恢复」/ 失败：「恢复副本失败」

**同步最新代码**（副本存在且有更新时）：
- 按钮：「同步代码」（图标 sync）
- 更新提醒：橙点 + 「有更新」
- 悬停提示：「拉取发布者最新代码，覆盖本地副本」
- 确认弹窗：「同步到最新代码？」+ 「将使用发布者最新代码覆盖你本地的副本，未保存的本地修改会丢失。是否继续？」
- 进行中：「同步中…」/ 成功：「已更新到最新版本」/ 失败：「同步代码失败」

**立即使用**：「立即使用」（策略资产为「打开策略」→ 跳转 `/strategy-ide`）

### 2.7 我的发布 / 我的购买

**我的发布**（作者后台）：
- 顶部统计卡：已发布指标（含已通过/待审核/已驳回计数）、总销量、总收入（积分）、平均评分
- 下方 Tab：「我的发布」（表格列：指标名称+类型标签、审核状态、当前售价、销量、累计收入、评分、操作）、「销售明细」（时间、买家、指标、本笔收入）
- 操作：查看销售、到市场查看、**下架**（确认：「下架这个资产？」+ 「下架后新用户将无法在市场购买；已购买用户保留本地副本和购买权益。」→ 「已下架」）

**我的购买**：
- 入口：市场头部「我的购买」链接
- 弹窗标题：「我的购买」，空态：「暂无购买记录」
- 列表项：指标名（可点击打开详情）、卖家、购买时间、购买价格（「我的购买价」）、免费标识
- 操作：「恢复副本」/「打开策略」/「立即使用」

### 2.8 过拟合风险与综合评分

**综合评分**：
- 范围 0-100，基于「回测的收益率/夏普/回撤/胜率/盈亏比/稳定性加权计算」
- 样本信息：「共 {n} 次回测样本」
- 策略卡上以奖杯图标 + 数字徽章展示（色级同上 2.3）

**过拟合风险仪表盘**（四等级）：

| 等级 | 标签 | 提示文案 |
|------|------|----------|
| 低 | 「稳健」 | — |
| 中等 | 「关注」 | 「策略表现较好，建议结合样本量与不同标的验证。」 |
| 高 | 「警惕」 | 「策略收益偏高，存在过拟合可能，请谨慎参考。」 |
| 极高 | 「极高」 | 「策略收益异常偏高，极可能过拟合，实盘前务必多标的、多样本验证。」 |

气泡提示：「基于策略 KPI 的启发式风险评估（{score}/100），样本 {n} 次。不代表未来表现。」

**净值曲线**：
- 标题：「净值曲线」
- 说明：「数据来自该指标得分最高的一次回测，仅供参考」
- 缺失：「该指标尚无可展示的净值曲线（暂无回测数据）」

### 2.9 策略模板的购买→绑定账户→启动流程

市场中**没有**「策略模板」Tab。市场中只有「指标」与「策略」两种资产类型。

策略模板（Bot Preset）的入口在「实盘」页：
- 购买策略资产后 → 跳转 `/strategy-ide` 编辑、回测并配置运行账户
- 成功提示：「已添加到Strategy API V2 策略，可在Strategy API V2 策略页编辑与回测」

点击「创建实盘」→ 弹出 `LiveStrategyEditor` 模态弹窗（宽 880px）：

**步骤 0：策略源码**
- 「策略源码」下拉框（从后端拉取策略列表）
- 选中后显示：源码信息卡（名称、类型标签 CTA策略/截面策略、描述、周期、参数数量）+ 策略 V2 契约摘要（策略类型、标的池、周期、市场）
- 「下一步」

**步骤 1：运行配置**
- 「策略名称」输入框
- 「投入金额（保证金）」输入框（最小 1，最大 1e9，步长 1000）
- 「启用杠杆」开关（仅 Crypto Swap 且策略 manifest 允许时可用）
- 杠杆倍数输入（范围 1-maxLeverage，步长 0.5）
- 账户风险限制（仅 Crypto Swap 且策略 manifest 要求方向模式时）：
  - 最大总敞口名义金额 / 单标的最大名义金额 / 最大保证金估算 / 最大总杠杆 / 单次往返手续费上限 / 每结算周期最大资金费率
- 「下一步」

**步骤 2：信号 & 实盘**
- **执行模式**单选：
  - 「仅信号通知」：系统只发送信号与提醒，由用户手动决定是否下单
  - 「实盘自动交易」：策略直接连接交易账户自动执行（仅当 `supportsLive` 为 true 时可选，即 Crypto 或 USStock）
- 若选实盘：
  - 复选框：「我已阅读并理解上述免责声明，仍选择开启实盘交易」
  - 「我的账户」下拉框（从已保存凭证中选择；无可用账户时显示「当前市场下没有可用的已保存账户」+ 「前往配置」跳转 `/broker-accounts`）
  - 「方向模式」单选：做多 / 做空 / 双向 / 中性（策略源码未声明方向时需手动选择）
  - 交易所标签
- **通知渠道**多选（必填）：浏览器 / 邮件 / Telegram / Discord / Webhook / 电话
- 确认创建 → 后端根据是否编辑走 create / update → 「策略创建成功」/ 「策略更新成功」

编辑已有策略时（路由 `/strategy-center?mode=edit&strategy_id=`），三步加载已有配置，确认按钮「确认修改」。

> 旧版「未回测的脚本启动 Live 会拦截提醒『先去回测』」的 key 在字典中存在，但**当前组件未引用**，当前编辑器步骤 0 选择源码后直接进入步骤 1。

## 7. 账户（实盘券商账户）

**路由**：`/broker-accounts` | **页面标题**：「实盘券商账户」

### 7.1 页面结构

**主内容区**（选中券商 → BrokerPanel，选中加密交易所 → CryptoExchangeAccountsCard）

### 7.2 加密交易所账户

**区块标题**：「加密交易所账户」
**副标题**：「这些账户以加密方式保存在数据库，模板策略与策略实盘下单时按账户名调用。支持 Binance / Bitget / Bybit / OKX / Gate.io / HTX。」

**空状态**：「暂无加密交易所账户」+ 「点击添加你的第一个交易所账户」

**账户列表项**：交易所图标 + 名称 + 「·」 + 账户别名（或「未命名」）+ API Key 提示（脱敏）+ 创建时间
- 「查看账户持仓」/ 「编辑名称」/ 红色「删除」

**删除确认**：「确认删除「{name}」？删除后使用该账户的策略将无法下单，且无法恢复。」→ 「账户已删除」

**编辑名称**：「编辑账户名称」→ 输入新名称（placeholder：「如：主账户、测试账户」）→ 「账户名称已更新」+ 「仅修改显示备注，不会更改 API Key 或密钥。」

**添加账户**（弹窗流程）：
1. 选择交易所（分组：加密货币交易所 / 美股 & 加密 / 美股券商）
2. 账户名称（可选）
3. 加密交易所额外字段：
   - 交易环境：实盘 / 模拟盘 / 测试网（按交易所不同可用选项不同）
   - 市场范围：现货和合约 / 仅现货 / 仅合约
   - API 白名单 IP（显示 IPv4 / IPv6，支持复制，可刷新）
   - API 密钥 / 秘密钥匙 / 密码短语（仅 OKX / Bitget 必填）
4. 「测试连接」按钮 → 「连接成功」/ 「连接失败」
5. 成功：「交易所账户添加成功」

**连接表单**：

- 秘密钥匙（placeholder：「从 Alpaca Dashboard 获取」）

### 7.5 IBKR 连接

**连接表单**：

- 只读模式开关 → 「只读模式下无法下单，仅用于查询。」

**常用预设按钮**：TWS Live (7496) / TWS Paper (7497) / Gateway Live (4001) / Gateway Paper (4002)

**帮助文本**：「IBKR 需要在本机或可达网络运行 TWS / IB Gateway。请确保已在 TWS 中启用 API 访问。」

### 7.7 持仓

- 进入：「持仓」Tab → `BrokerPositionsTable`
- 表格列：代码 / 方向 / 数量 / 均价 / 市值 / 浮动盈亏（正绿负红）
- 「刷新」按钮 + 「共 {count} 个持仓」
- 数据来源：`GET /api/{brokerId}/positions`

### 7.8 订单记录

- 进入：「订单记录」Tab → `BrokerOrdersTable`
- 表格列：订单 ID（200px 省略） / 代码 / 方向（buy 绿 / sell 红） / 数量 / 限价 / 状态（filled=green、canceled/rejected/expired=default、partially_filled/new=blue、其它=orange） / 操作
- 「刷新」按钮 + 「共 {count} 条最近订单」
- **撤单**：按钮「撤单」→ 确认「确认撤销该订单？」→ 「订单已撤销」/ 「撤单失败」
- 数据来源：`GET /api/{brokerId}/orders`、`DELETE /api/{brokerId}/order/{id}`

### 7.9 下单操作

`BrokerAccounts` 页暴露 `place-order` 事件与 `handlePlaceOrder` 方法，但**当前编译产物中未包含下单表单 UI**。下单表单由 `QuickTradePanel`（「闪电交易」）独立承载，在交易图表页嵌入。

- 接口：`POST /api/{brokerId}/order`，Body: `{ symbol, side, qty, type, price?, source? }`
- 成功：「订单已提交」/ 失败：「下单失败」

### 7.10 连接管理

- 状态卡：品牌图标 + 券商名 + 连接状态圆点 + 状态文案 + 账号/主机/端口信息
- 「刷新」/ 「断开」按钮 → 「已断开」/ 「断开失败」
- 连接成功自动切换到「账户概览」Tab
